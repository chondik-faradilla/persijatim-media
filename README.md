# persijatim-media

Video latar hero beranda persijatim.id (Suramadu, Bromo, Kawah Ijen).
Disajikan lewat GitHub Pages karena hosting persijatim.id tidak mengizinkan file video.

- `video/desktop/` loop 8 detik per slide + transisi antar-slide (1920 px)
- `video/hp/` loop versi tegak untuk HP

Dipakai oleh tema `persi-jatim` (atribut `data-video-base` di pola hero).
